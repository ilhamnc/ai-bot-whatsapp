Grup tujuan AiBot

Ketik !idgrup di grup WhatsApp. Grup itu otomatis menjadi target saat pilihan belum dikunci.

Bantuan AiBot

Panduan singkat untuk mengatur dashboard dan memakai bot di WhatsApp.

1. Hubungkan WhatsApp

  1. Jalankan npm run dev, lalu buka dashboard lokal.
  2. Buka Pengaturan → Set WA Bot. Jika ada QR, pindai dari WhatsApp → Perangkat tertaut → Tautkan perangkat.
  3. Ketik !idgrup di grup. Atur atau kunci pilihan lewat Pengaturan → ID Grup Bot.
  4. Untuk perintah admin, ketik !myid di grup target dan masukkan ID dari terminal ke BOT_ADMIN_IDS pada .env.

2. Pengingat biasa

  • Klik Tambah pengingat; pilih hari, satu atau beberapa jam, lalu isi pesan.
  • Pakai @all atau @semua jika ingin menyebut seluruh anggota grup.
  • Gunakan toggle pada kartu untuk mengaktifkan satu pengingat. Toggle di atas halaman mengatur seluruh pengiriman.
  • Negara, kota, dan zona waktu diatur lewat Pengaturan → Zona Waktu. Zona itu juga dipakai pengingat biasa.

3. Pengingat shalat

  • Aktifkan toggle Jadwal shalat, lalu buka Detail & edit pesan.
  • Pilih semua waktu atau beberapa dari Subuh sampai Isya. Isi pesan untuk waktu yang dipilih dan klik Simpan pesan.
  • Klik Cek jadwal hari ini untuk melihat jam sesuai lokasi.
  • AI mencoba memvariasikan pesan; jika AI tidak tersedia, teks yang tersimpan tetap digunakan.

4. Perintah WhatsApp

  • !ai pertanyaan, mention @AiBot, atau balas pesan bot untuk bertanya ke AI di grup target.
  • !schedule melihat jadwal; !status, !model, dan !memori melihat status.
  • !help menampilkan bantuan di chat pribadi atau grup.
  • Admin: !daftarbot @AiBot, !reminder on/off, !testkirim, dan !resetai.
